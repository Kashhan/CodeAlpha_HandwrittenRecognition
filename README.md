# Handwritten Character Recognition using CNN

## Objective
To recognize handwritten digits using a Convolutional Neural Network.

## Dataset
MNIST Dataset

## Features Used
- 28x28 grayscale pixel values of handwritten digits

## Approach
- Data normalization
- Reshaping images for CNN input
- Building a Convolutional Neural Network
- Training and evaluating the model on test data

## Model Used
Convolutional Neural Network (CNN)

## Architecture
- Convolutional layers
- MaxPooling layers
- Fully connected dense layers
- Softmax output layer

## Evaluation Metrics
- Accuracy

## Results
The model achieved approximately 97 to 99 percent accuracy on the test dataset.

## Conclusion
The CNN model successfully classifies handwritten digits with high accuracy, demonstrating the effectiveness of deep learning in image recognition tasks.

- Python
- TensorFlow
